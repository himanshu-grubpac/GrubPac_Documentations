StoreData kindWhat GrubData puts there
PostgreSQLStructured business dataUsers, searches, results, audit, video metadata, RBAC
S3Binary mediaVideo MP4, face upload images — not in Postgres
stdout → LokiOperational logsrequestId-correlated JSON log lines
PrometheusMetrics (target)Latency, errors, queue depth numbers
Kafka (target)Domain eventsSearch, audit, video lifecycle event streams
EC2 containersApplication codeDocker images only — deploy does not touch user rows

Postgres: All durable business data enters via the Express API or search worker. Frontend never touches DB directly.

S3: Video bytes and uploads — DB stores keys and JSON metadata only.

Audit: Every sensitive API action → audit_logs (async batch).

Deploy: GitHub → EC2 blue/green — changes code containers, not user data.

Next: Prometheus (metrics), Loki (logs), Kafka (events), Grafana (one UI) — parallel to Postgres, not replacing it.
