1. The 4 Tools — What Each Does in GrubData

Prometheus Metrics & SLIs

Time-series numbers: request rate, latency p95, error %, queue depth, worker duration, DB pool, EC2 CPU. Pull-based scraping every 15s.
SLIs/SLOs, capacity planning, deploy health, alert thresholds. Backend exposes /metrics via prom-client.

Loki Centralized Logs

Log aggregation without indexing full text. Labels: service, level, tenantId, searchId, requestId. Cheap at scale vs Elasticsearch.
Debug failures, correlate with metrics. Winston JSON → Promtail → Loki. Already compatible with current logger.

Grafana Single Pane of Glass

Dashboards + alerts on Prometheus + Loki + Kafka lag. One ops portal for dev, SRE, and government operators.
Search ops, video pipeline, auth security, infra health. Click metric spike → jump to logs by requestId.

Kafka Event Streaming Bus

Durable ordered event log. Many consumers, replay, backpressure. MSK — Amazon Managed Streaming for Apache Kafka — at enterprise scale. Complements (later replaces) SQS for search.
Search jobs, audit fan-out, video lifecycle, geo analytics, notifications, CDC to warehouse.

2. Today vs Target

Today: Winston JSON → stdout. Audit → in-memory queue → Postgres. Health at /api/v1/health. SQS optional for search. No Prometheus/Loki/Grafana/Kafka. Build on EC2 (docker compose up --build).

Target: CI builds images → ECR. EC2/ECS pulls images. Prometheus + Loki + Grafana stack. Kafka (MSK) for events at scale. Full requestId correlation.

22. Short Summary

Prometheus = numbers (latency, errors, queue depth, CPU). Scrape backend /metrics + exporters.

Loki = logs. Winston JSON → Promtail → search by requestId / searchId.

Grafana = one UI for metrics + logs + alerts. Click spike → see logs.

Kafka = event bus at scale (search jobs, audit, video, geo). MSK (Amazon Managed Streaming for Apache Kafka) in prod. Keep SQS until ready.

Build in GitHub → ECR. Prod only pulls images. Not docker compose --build on EC2.

GrubData coverage: API, auth, search (ANPR/face/surveillance), worker, S3, video request/stream, saved, map/dashboard, audit, Postgres, Redis, nginx, CI/CD, frontend.
